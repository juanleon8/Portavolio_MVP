Mis Proyectos

Around The U.S. — Tarjetas interactivas

¡Descubre y comparte los lugares más increíbles de Estados Unidos!

Descripción general del proyecto

Aplicación web interactiva donde el usuario puede ver, agregar, eliminar y dar "me gusta" a tarjetas de lugares, además de editar su perfil mediante modales totalmente funcionales. Está construida siguiendo buenas prácticas de HTML, CSS y JavaScript, con manipulación del DOM, clonación de templates y listeners dinámicos.

Características

  • Edición de perfil (nombre y descripción) mediante modales.
  • Agregar, eliminar y dar "me gusta" a tarjetas generadas dinámicamente.
  • Vista ampliada de imágenes con su título como caption.
  • Consumo de datos con la Fetch API y manejo de Promises.

Logros clave

  • Manipulación avanzada del DOM con templates y event listeners.
  • Modales totalmente funcionales sin recargar la página.
  • Integración con una API REST desde el servidor.

Resumen

Este proyecto muestra mi capacidad para construir interfaces interactivas y dinámicas, integrando datos de servidores externos con JavaScript moderno.

Gestor de Gastos Personales

Administra tu presupuesto y controla tus gastos por categorías.

Descripción general del proyecto

Aplicación web desarrollada con JavaScript Vanilla que permite administrar un presupuesto y registrar gastos por categorías. Calcula automáticamente estadísticas financieras y almacena la información localmente para mantener los datos entre sesiones.

Características

  • Asignar presupuesto y registrar nuevos gastos.
  • Eliminar gastos individuales y reiniciar la información.
  • Cálculo automático de gastos totales, promedio, saldo y categorías.
  • Persistencia de datos mediante LocalStorage.
  • Actualización dinámica de la interfaz sin recargar la página.

Logros clave

  • Manipulación dinámica del DOM con Templates HTML.
  • Gestión de eventos con Event Listeners y código modular.
  • Algoritmos para el procesamiento de estadísticas financieras.

Resumen

Este proyecto refleja mi solidez con JavaScript Vanilla: desde la manipulación del DOM hasta la persistencia y el cálculo de datos en tiempo real.

Jesús Mondragón Arquitecto

Sitio web profesional para un despacho de arquitectura moderna.

Descripción general del proyecto

Página web para Jesús Mondragón Arquitecto con diseño arquitectónico moderno y funcional. Presenta proyectos residenciales, comerciales y de remodelación diseñados de principio a fin, junto con un portafolio de proyectos destacados y un formulario para cotizar proyectos.

Características

  • Hero y secciones de servicios, proyectos y contacto.
  • Portafolio de proyectos destacados con diseño responsive.
  • Navegación con menú móvil y botones de llamada a la acción.
  • Identidad visual propia: logo, tipografías e imágenes del estudio.

Logros clave

  • Diseño de experiencia de marca para un despacho real.
  • Maquetación responsive de inicio a fin.
  • Recursos visuales propios (logos, imágenes y SVG).

Resumen

Este proyecto demuestra mi capacidad para crear sitios profesionales orientados a clientes, combinando una identidad visual sólida con una estructura clara y responsive.
